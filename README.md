# 扑克风云会 · 沙盘电子版

培训沙盘《扑克风云会》的电子化系统：多组登录、现场交易记账、利润表自动结算、小组 PK 自动排名、大屏投屏。

- 零依赖：仅需 Node.js ≥ 18，无需安装任何 npm 包
- 本地课堂模式：一台电脑启动，学员手机/电脑连同一 WiFi 访问
- 线上模式：部署到 Render 免费版，学员浏览器直接访问公网地址

## 本地运行

```bash
node server.js --port 7100
# 或双击 双击启动沙盘.bat（Windows）
```

打开 `http://localhost:7100/`，讲师用管理口令（默认 `8888`，可用环境变量 `ADMIN_CODE` 修改）进入管理端。

## 免费部署到 Render（约 3 分钟）

1. 注册/登录 [Render](https://render.com)（可用 GitHub 一键登录，免费、无需信用卡）
2. 首页点 **New → Blueprint**，选择本仓库（`poker-sandbox`），Render 会自动识别 `render.yaml`
3. 按提示填写环境变量 **ADMIN_CODE**（自定义管理口令，不要用默认 8888），点 **Apply**
4. 等待构建完成，得到 `https://poker-sandbox.onrender.com` 这样的网址，发给学员即可

说明：
- Render 免费版闲置约 15 分钟会休眠，再次访问约需 30–60 秒唤醒；上课时各端每 3 秒自动刷新，会保持唤醒，不影响使用
- 免费版重启后账目数据会清空（每堂课本身就是新的一局，重开即可）
- 每轮结算、技能效果（品牌溢价/批量折扣/自建仓库/深度加工等）均由服务端自动计算

## 页面

| 页面 | 用途 |
|---|---|
| `/` | 登录页（小组选队名+口令；讲师管理口令入口） |
| `/team.html` | 小组经营台（记账、利润表、技能使用） |
| `/admin.html` | 讲师管理端（规则参数、拍卖、计时、结算、清算） |
| `/board.html` | PK 投屏大屏（倒计时、排名、交易播报） |
